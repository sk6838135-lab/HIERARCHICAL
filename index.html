Hierarchical Clustering

Understanding how machine learning groups similar data points into a hierarchy of clusters using distance, mathematical methods, and real-world examples.

Start Learning ↓

01. Introduction

Hierarchical Clustering is an unsupervised machine learning algorithm that groups similar data points into clusters. It creates a hierarchy of groups that can be visualized using a tree-like diagram called a dendrogram.

Unlike algorithms that require the number of clusters in advance, hierarchical clustering allows us to examine different levels of grouping and choose an appropriate number of clusters later.

Key idea: Similar data points are grouped together, while dissimilar data points are separated into different clusters.

Type of Machine Learning

  • Learning type: Unsupervised learning
  • Input: Data without predefined class labels
  • Output: Nested groups of similar observations
  • Visualization: Dendrogram

02. Description and Working

There are two main approaches to hierarchical clustering.

A. Agglomerative Clustering

This is a bottom-up approach. Initially, every data point is treated as a separate cluster. The closest clusters are repeatedly merged until all points belong to one cluster or the required stopping condition is reached.

B. Divisive Clustering

This is a top-down approach. Initially, all data points belong to one cluster. The algorithm repeatedly divides clusters into smaller groups.

Feature Agglomerative Divisive
Approach Bottom-up Top-down
Starting point Each point is separate All points are together
Main operation Merge clusters Split clusters

Steps of Agglomerative Clustering

  1. Collect and prepare the dataset.
  2. Calculate distances between data points.
  3. Treat each observation as a separate cluster.
  4. Merge the two closest clusters using a linkage method.
  5. Repeat the process and record the merging distances.
  6. Draw a dendrogram and select a suitable cluster count.

03. Mathematical Formula

Clustering commonly begins by measuring the distance between data points. For numerical data, one popular method is Euclidean distance.

d(A,B) = √[(x₂ − x₁)² + (y₂ − y₁)²]

Consider two points:

  • Point A = (2, 3)
  • Point B = (5, 7)

Step-by-step calculation

Step 1: Substitute the coordinates.

d = √[(5 − 2)² + (7 − 3)²]

Step 2: Calculate the differences.

d = √[3² + 4²]

Step 3: Square and add the values.

d = √[9 + 16] = √25

Final answer:

d(A,B) = 5

The distance between the two points is 5 units. A smaller distance generally indicates greater similarity under this distance measure.

Linkage methods

Method Meaning
Single linkage Minimum distance between points in two clusters.
Complete linkage Maximum distance between points in two clusters.
Average linkage Average pairwise distance between two clusters.
Ward's method Merges clusters to minimize the increase in within-cluster variance.
Important: The distance formula measures similarity between individual points. Linkage determines how the distance between entire clusters is calculated.

04. Understanding a Dendrogram

A dendrogram is a tree diagram showing when clusters merge and the distance at which they merge. The vertical height of each joining point represents the linkage distance.

In this illustrative diagram, A and B form one group, while C and D form another. These groups later merge into a larger cluster.

05. Python Implementation

We can use Python's scikit-learn library to perform agglomerative clustering. This example groups customers based on annual spending and visit frequency.

Python code

import pandas as pd
from sklearn.cluster import AgglomerativeClustering
from sklearn.preprocessing import StandardScaler

data = pd.DataFrame({
    "Spending": [20, 22, 25, 70, 75, 80],
    "Visits": [2, 3, 2, 8, 9, 8]
})

X = StandardScaler().fit_transform(data)

model = AgglomerativeClustering(n_clusters=2)
data["Cluster"] = model.fit_predict(X)

print(data)

Code explanation

  • pandas: Stores the customer data in a table.
  • StandardScaler: Scales both features to comparable units.
  • AgglomerativeClustering: Performs hierarchical clustering.
  • n_clusters=2: Requests two final clusters.
  • fit_predict(): Groups each observation and returns its cluster label.

06. Data Analysis and Statistics

Hierarchical clustering is mainly used to discover groups rather than predict a target value. The quality of the groups can be examined using suitable clustering metrics.

Distance matrix

Shows pairwise distances between observations or clusters.

Dendrogram

Helps examine cluster merging and choose a cut level.

Silhouette score

Measures how well observations fit their own clusters compared with others.

Cluster size

Shows the number of observations assigned to each group.

Silhouette score

s = (b − a) / max(a, b)

Here, a is the average distance to points in the same cluster, and b is the lowest average distance to points in another cluster.

  • A score close to +1 generally indicates well-separated clusters.
  • A score around 0 suggests overlapping clusters.
  • A negative score may indicate that some points fit another cluster better.
The appropriate metric depends on the data and the clustering goal. There is no single statistic that proves a clustering result is correct in every situation.

07. Real-World Applications

1. Customer segmentation

Businesses can group customers by spending, purchase frequency, and other characteristics to understand different customer types.

2. Healthcare

Researchers can explore similarities between patient records or biological measurements to identify patterns for further study.

3. Document grouping

Similar articles, reports, and documents can be grouped using numerical representations of their content.

4. Biology and genetics

Hierarchical clustering can help visualize similarities among species, genes, or biological samples.

5. Image analysis

It can group image regions or image features based on their similarities.

Advantages

  • Does not require predefined class labels.
  • The dendrogram makes nested relationships easier to inspect.
  • Different cluster counts can be explored by cutting the hierarchy.

Limitations

  • Can be computationally expensive for large datasets.
  • Results can be affected by scaling, distance choice, and linkage method.
  • Early merge decisions are generally not undone in standard agglomerative clustering.
  • Choosing the final number of clusters may require interpretation.

08. Conclusion

Hierarchical Clustering is an unsupervised machine learning technique that organizes similar observations into a hierarchy of clusters. Agglomerative clustering combines small groups, while divisive clustering splits larger groups.

Distance measures and linkage methods determine how groups are formed, and a dendrogram helps us understand the structure. It is useful in customer segmentation, healthcare research, document analysis, and biological studies.

Final takeaway: Hierarchical clustering helps discover the hidden structure of data without requiring predefined labels. Good results depend on suitable preprocessing, distance measures, linkage methods, and interpretation.
